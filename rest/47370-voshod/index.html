Воскресный бранч-безлимит за 7000 ₽ с человека (люди так празднуют дни рождения — выходит дешевле общего стола). Проверял, можно ли наесть больше, чем заплатил, — и окупился уже к середине. Из ~25 позиций: манты 10/10, долма 8,5 (сочнейшая), утиная ножка в унаги 7, креветочные котлеты в грибном соусе — «песня», котлета из оленя в беконе — замечательно, кебапчичи 9, картошка с лисичками 10/10, рыба с томатами 9, жареный микро-хинкаль с сыром 8, каракатица 7 («как курица»), жульен с рваной говядиной — «12 из 10, максимум 100», краб 9, лангустины с песто феноменальные, копчёный кальмар тает на языке, роллы с красной рыбой 9. Провалы: рёбра сухие, рыба холодного копчения 5, салат с кальмаром «СССР» 3, холодец «не моё». Сервис — «как за пупсиком ухаживают». По воскресеньям в мужском туалете появляется призрак Олег.
