Честный обзор ресторана стендап-комика Сергея Орлова — с извинениями за предвзятость, потому что место оказалось сильным. Шмак «Брюс Ли» и сырный рамен — два блюда уровня «обязательно попробовать», сэндвич с тунцом отличный. Моти разочаровали, лимонад нормальный. Интерьер стильный, цены для центра адекватные. Один из лучших «звёздных» ресторанов по версии канала.
